# APT Repository (Ubuntu & Debian)

This directory contains the APT repository metadata (`dists/` and `pool/`).

### DEB822 Configuration (`/etc/apt/sources.list.d/podman-isolated.sources`):

```text
Types: deb
URIs: https://xpufx.github.io/podman-isolated-pkgs/apt
Suites: stable-2404
Components: main
Signed-By: /etc/apt/keyrings/podman-isolated.gpg
```
