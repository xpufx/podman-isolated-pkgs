# Podman Isolated Package Repository

This repository hosts pre-built, isolated packages and repository metadata for the **Podman Isolated** project.

The packages hosted here provide standalone, prefix-installed builds of the upstream Podman container engine and its companion OCI stack (crun, conmon, netavark, aardvark-dns, etc.) that install side-by-side with system packages without collisions.

## Installation & Documentation

For repository setup instructions, supported distributions, and usage details, please visit the documentation site:

**[https://xpufx.github.io/podman-isolated-pkgs/](https://xpufx.github.io/podman-isolated-pkgs/)**

## Source Code & Build Automation

The underlying build automation, CI pipelines, and packaging source code are maintained in the upstream project repository, which will become public in due course.
